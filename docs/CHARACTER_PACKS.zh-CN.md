# 导入自己的角色

右键小人 → **外观 → 导入角色…**。选择后立即切换，下次打开仍使用这个角色。导入内容会复制到 `~/Library/Application Support/Sisyphus/Characters/`，原文件可以移动。通过同一菜单可切回其他角色。

支持三种输入：

- **透明 PNG**：一张全身图即可使用。没有额外动作帧时会保持这一张图，仍然可以移动、攀爬和拖动。
- **标准 Shimeji 图片文件夹**：选择直接包含 `shime1.png` 的文件夹，或其上一级（图片放在 `img/`）。带多角色的包，请进入 `img/角色名/` 选中对应目录。无需运行 Java 程序。
- **自定义动作包**：同一目录放 `character.json` 和 PNG 精灵图。可以直接导入配置文件或其所在目录。

标准 Shimeji 导入读取 1、2、3、4、5、6、11、14、15、16 号图片，对应站立、行走、掉落、拎起、落地和爬行。缺少动作会回退到站立。只导入图片，不执行 JAR、XML 行为表达式或脚本；非标准编号请转换为下面的 JSON。

## 动作包格式

可参考项目里的 `Resources/Characters/Akane/character.json`。精灵图按从左到右、从上到下编号，第一帧是 0。每格尺寸相同，PNG 宽高必须分别整除列数和行数。

```json
{
  "version": 1,
  "name": "我的桌宠",
  "image": "sprite.png",
  "columns": 4,
  "rows": 3,
  "renderHeight": 104,
  "facesRight": true,
  "animations": {
    "idle": { "frames": [0, 1], "fps": 2 },
    "walk": { "frames": [2, 3], "fps": 6 },
    "climb": { "frames": [4, 5, 6, 7], "fps": 4, "anchor": [0.5, 0.79] },
    "fall": { "frames": [8], "fps": 1 },
    "drag": { "frames": [9, 10], "fps": 3 },
    "recover": { "frames": [11], "fps": 1 }
  }
}
```

只有 `idle` 必需，缺少其他动作会使用它。`renderHeight` 为 64–120 点的期望高度，实际会等比缩放到角色的小窗口内。`facesRight` 表示原图朝向，省略为朝右；标准 Shimeji 自动设为朝左。

`anchor` 为可选的 `[x, y]`，取值 0–1，原点在动作格的**左下角**。站立动作的锚点对齐地面，攀爬动作的锚点对齐手部支点，悬空动作对齐身体位置。留白很大的素材可以用这个设置校正位置。裁切编号使用从上到下的行顺序，与锚点坐标不是同一含义。

文件限制：配置 ≤ 256 KiB，PNG ≤ 32 MiB / 1600 万像素，行列各 ≤ 16，动作帧率 0–30（不含 0）。标准 Shimeji 单帧不超过 1024 × 1024。图片只能引用配置文件同目录内的 PNG；不允许跳到其他路径或通过符号链接读取目录外文件。

桌面采样仍排除 Sisyphus 自己，因此角色图片不会被识别成自己的攀爬地形。

内置新条茜为同人动作图，生成记录与来源见 [CHARACTER_ART.md](CHARACTER_ART.md)。导入功能不自动授予第三方角色素材的再发布权。
