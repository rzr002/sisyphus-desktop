# 0.3.0 验证记录

在 Apple Silicon Mac 上验证核心运动、窗口行为、真实屏幕读取，并从桌面录像检查人物与蛛丝的位置。

## 可重复的检查

```bash
bash scripts/swift-local.sh run ClimbChecks
bash scripts/swift-local.sh build --product Sisyphus
python3 scripts/check-native.py
bash scripts/package-app.sh
```

- 50 项核心检查通过。覆盖普通攀爬、横向巡逻、逐行换手、拖拽、局部擦除、角色导入，以及蜘蛛侠跨越纵向和横向空档、摆荡折返、断丝和暂停。
- 24 项原生检查通过，覆盖角色窗口尺寸、右键入口、输入穿透、各姿势裁切、浮动窗口支点归属、角色选择持久化，以及在已授权环境中读取主显示器。运行检查需要图形会话，只有具备录屏权限时才执行两项屏幕读取检查。
- 角色包内的图像在加载时解码。测试核对背身攀爬帧、透明通道、帧编号、导入后的独立存储和路径边界。
- 发布脚本会构建 Apple Silicon 或当前 Mac 架构的原生程序、验证代码签名，并在 `dist/` 写入 ZIP 和可用 `shasum -a 256 -c` 检查的同名校验文件。

## 实录里可以核对的动作

前十秒在演示用的可编辑 AppKit 文档中拍摄。蜘蛛侠从「街角的灯」发丝跨向上方的段落，然后在固定字形下左右折返。文档删除上方段落之后，丝端脱开，人物落到屏幕底部。下方的段落一直留在原位。

后五秒来自 macOS 自带的「文本编辑」。新条茜背对观看者，沿真实文档中的文字向上换手。取景只保留演示文档和人物，影片经过裁切、拼接并附简体中文字幕。[桌面实录](media/desktop-demo.mp4)

当前安装包适用于 Apple Silicon 和 macOS 14 以上，使用 ad-hoc 签名。活动区域为主显示器。用户系统的录屏授权和可见内容会影响实际路线。
