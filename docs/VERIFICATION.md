# 0.4.0 验证记录

在 Apple Silicon Mac 上验证核心运动、窗口行为、真实屏幕读取，并用公开的原生文档和系统壁纸离屏检查人物与蛛丝的位置。

## 可重复的检查

```bash
bash scripts/swift-local.sh run ClimbChecks
bash scripts/swift-local.sh build --product Sisyphus
python3 scripts/check-native.py
bash scripts/package-app.sh
```

- 55 项核心检查通过。覆盖普通攀爬、横向巡逻、逐行换手、拖拽、局部擦除、角色导入，以及蜘蛛侠跨越纵向和横向空档、摆荡折返、跨支点换手时的双腕、空中翻身与重新挂丝、断丝和暂停。
- 27 项原生检查通过，覆盖角色窗口尺寸、右键入口、输入穿透、两种朝向和两只出丝手的姿势裁切、各动作的剪影差异、重复运行互斥、退出后重开、浮动窗口支点归属、角色选择持久化，以及在已授权环境中读取主显示器。运行检查需要图形会话，只有具备录屏权限时才执行两项屏幕读取检查。
- 角色包内的图像在加载时解码。测试核对背身攀爬帧、透明通道、帧编号、导入后的独立存储和路径边界。
- 发布脚本会构建 Apple Silicon 或当前 Mac 架构的原生程序、验证代码签名，并在 `dist/` 写入 ZIP 和可用 `shasum -a 256 -c` 检查的同名校验文件。

## 低位摆荡回归

用 6 种高度、4 种间距，以及正常 60 Hz / 双速 20 Hz 共 48 种组合跑同一个用例。修复前，支点静止时发生过 150 次触地误坠。修复后，572 次换锚、154 次翻身中没有误坠；身体基准点最低离游戏地面 18 pt。这组数值来自确定性的核心仿真，不是对任意桌面的承诺。主动删字、移动窗口或鼠标碰落的用例也继续执行。

## 首页动图的来源

[完整桌面动图](media/mac-desktop.gif) 使用 macOS 自带壁纸、固定的系统应用图标和两份自写的示例内容。两个 AppKit 窗口离屏绘制，从不显示在用户桌面上。渲染器对这张完整画面运行产品的地形检测、换锚状态机和角色绘制，路线没有预设。它是隐私安全的玩法演示，并非用户桌面的实录。

在带 Sonoma 系统壁纸和 FFmpeg 的 Apple Silicon Mac 上，用 `bash scripts/render-preview.sh` 可以重新生成。脚本不需要录屏授权，不枚举用户窗口或 Dock，不读取用户文件，也没有音轨。

当前安装包适用于 Apple Silicon 和 macOS 14 以上，使用 ad-hoc 签名。活动区域为主显示器。用户系统的录屏授权和可见内容会影响实际路线。
