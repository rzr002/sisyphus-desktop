# 最终产品验收

1. 启动后只出现小人：无面板、练习窗口、气泡、统计、Dock 图标或状态栏图标。
2. 小人只根据真实桌面的像素纹理找路，均匀色块内部无法攀爬。
3. 右键小人或 Control + 单击可打开原生菜单。菜单打开时小人不移动。
4. 左键拖动可移动人物；松手恢复重力；位置被限制在可操作的屏幕范围内。
5. 鼠标有意停在小人身上时保持稳定；快速掠过触发干扰；菜单和拖动之后不会误触发干扰。
6. 文字/图像的承重点被删除后释放抓握，画面删除后静止也不会无限悬空。
7. 支持暂停/继续、重新出发、鼠标干扰开关、三档速度与退出，均在右键菜单中。
8. 只有小人尺寸的窗口接收鼠标。键盘焦点仍属于用户正在操作的应用。
9. 没有拿到真实屏幕帧时，小人原地等待；右键菜单显示「桌面读取尚未生效」，提供「重新连接桌面」和「屏幕录制权限…」，没有自制权限面板。
10. 退出后不残留窗口或屏幕流。
11. App 安装至应用程序后可从启动台打开；运行时隐藏 Dock 图标。

12. 蜘蛛侠会用蛛丝跨过超过普通手臂可达范围的空档。固定锚点下能自主向两侧摆荡，删掉锚点时断丝掉落。
13. 前方有支点时可交替换手，短暂同时显示两根丝。有净空时可松丝翻身，再向真实支点出丝。
14. 重复启动只保留一个桌宠；退出后能再次启动。
15. 蛛丝允许点击穿透，拖动角色、切换普通外观和退出都会收起蛛丝。
